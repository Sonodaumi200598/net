# 异构聚合网络视频回传技术文档

本仓库用于编写“无人机、无人车实时图像回传”场景下，聚合路由器到聚合服务器之间的异构聚合网络传输技术文档。

当前文档范围聚焦于：

```text
聚合路由器 -> 异构链路 -> 聚合服务器
```

不展开无人机飞控、无人车运动控制、摄像头硬件选型、上层业务平台和 AI 图像识别算法。
