# 第 2 章 异构链路基础

## 2.1 异构链路类型

在无人机、无人车实时图像回传场景中，聚合路由器可能同时接入多种链路。不同链路在带宽、时延、覆盖范围、稳定性和费用方面存在明显差异。

- 4G 链路：覆盖范围广，带宽中等，时延和抖动受基站负载影响明显。
- 5G 链路：带宽较高，时延较低，但移动状态和覆盖环境会影响稳定性。
- Wi-Fi 链路：部署方便，局部区域带宽较高，但抗干扰能力有限。
- 有线以太网链路：稳定性高，常用于地面调试、固定站点或服务器侧接入。
- 专网链路：可包括 LTE 专网、Mesh 电台、COFDM 等，适合行业场景。
- 卫星链路：覆盖范围广，适合偏远地区，但时延通常较高。
- Mesh 自组网链路：适合多节点协同场景，但链路质量随拓扑变化而波动。

## 2.2 各类链路基本特性

| 链路类型 | 带宽特性 | 时延特性 | 抖动特性 | 丢包特性 | 稳定性 |
|---|---|---|---|---|---|
| 有线以太网 | 高且稳定 | 低 | 低 | 低 | 高 |
| Wi-Fi | 中高，受干扰影响 | 中等 | 中高 | 中等 | 中等 |
| 4G | 中等，波动明显 | 中高 | 中等 | 中等 | 中等 |
| 5G | 高，随覆盖变化 | 低到中等 | 中等 | 中等 | 中高 |
| 卫星 | 中等 | 高 | 高 | 中高 | 中等 |
| 专网/Mesh | 中等 | 中等 | 中等 | 低到中等 | 中高 |

## 2.3 无人机场景下链路特点

- 飞行高度、姿态和距离变化会导致无线信号质量波动。
- 空地链路可能受到建筑、山体、树木等遮挡。
- 任务范围较大时可能需要 5G、专网、卫星等多种链路协同。
- 高速移动会带来链路切换、信号衰落和短时中断。
- 视频回传对上行带宽和时延稳定性要求较高。

## 2.4 无人车场景下链路特点

- 城市道路环境中建筑遮挡和多径效应明显。
- 车载平台通常可同时接入 5G、Wi-Fi、专网和有线调试链路。
- 多摄像头并发时，上行链路带宽压力较大。
- 车辆经过隧道、地下区域、建筑密集区域时链路质量可能急剧下降。
- 视频连续性对远程驾驶、巡检和安全监控具有重要意义。

## 2.5 链路基础参数

- 带宽：链路理论带宽、可用带宽和实际吞吐量。
- 时延：单向时延、往返时延和排队时延。
- 抖动：连续数据包到达间隔的变化程度。
- 丢包率：发送包与接收包之间的缺失比例。
- 误码率：链路传输中比特错误的概率。
- MTU：链路可承载的最大传输单元。
- 链路可用时间：链路保持正常通信的持续时间。
- 链路中断时间：链路失效到恢复之间的时间。
- 链路恢复时间：链路重新加入传输系统所需时间。
