# 第 11 章 基础技术层输出内容

## 11.1 对上层提供的能力

- 可用链路列表。
- 每条链路的接口名、IP 地址、网关和在线状态。
- 基础链路质量参数，包括 RTT、丢包率、抖动和吞吐量。
- 按指定链路发送数据的接口能力。
- 从多条链路接收数据的接口能力。
- 基础安全通道和身份认证能力。
- 视频流输入输出接口。

## 11.2 基础技术层约束

- 单个数据包大小应尽量小于路径 MTU，避免 IP 分片。
- 多网卡路由必须可控，避免数据包走错出口链路。
- 链路状态必须可观测，便于上层调度算法及时调整。
- UDP 不提供可靠传输，丢包、乱序和重复包需要上层处理。
- TCP 的可靠性可能引入额外等待和队头阻塞。
- 实时视频不适合无限等待重传，需要设置超时和丢弃策略。

## 11.3 基础技术层评价指标

- 链路连通率。
- 基础 RTT。
- 基础丢包率。
- 基础抖动。
- 单链路吞吐量。
- 多链路总可用带宽。
- 网卡切换检测时间。
- 链路中断检测时间。
- CPU、内存和网卡资源占用。
