# 第 3 章 IP 网络基础

## 3.1 IP 地址与网络接口

聚合路由器和聚合服务器之间的通信依赖基础 IP 网络能力。需要掌握 IPv4、IPv6、子网掩码、默认网关、DNS、静态地址配置和 DHCP 动态地址分配等基础概念。

在多链路聚合场景中，每条物理链路或逻辑隧道通常对应一个独立网络接口和源 IP 地址，因此 IP 地址与接口绑定关系是后续策略路由和链路选择的基础。

## 3.2 多网卡环境

聚合路由器常见接口示例如下：

```text
eth0  ：有线以太网链路
wlan0 ：Wi-Fi 链路
wwan0 ：4G/5G 蜂窝链路
sat0  ：卫星链路
mesh0 ：专网或 Mesh 链路
```

多网卡环境需要解决默认路由冲突、出口链路选择、源地址选择、网卡优先级、链路断开与恢复等问题。

## 3.3 IP 路由基础

- 路由表：决定目标地址对应的下一跳和出口网卡。
- 默认路由：目标地址无明确匹配时使用的路由。
- 静态路由：人工配置的固定路由规则。
- 策略路由：根据源地址、fwmark、接口等条件选择不同路由表。
- 路由优先级 metric：用于多条候选路由之间的优先选择。

## 3.4 NAT 与公网可达性

无人机和无人车侧的聚合路由器通常处于运营商网络或现场局域网内，可能经过 NAT 或 CGNAT。聚合服务器一般部署在公网或中心机房，作为稳定的接收端。

基础技术层需要考虑私网地址、公网服务器、端口映射、UDP NAT 保活和 NAT 穿越问题。对于实时视频回传，较常见的方式是由聚合路由器主动向公网聚合服务器建立传输通道。

## 3.5 MTU 与分片

视频数据包较大时需要特别关注 MTU。若单个 UDP 包超过路径 MTU，IP 层可能发生分片。分片会放大丢包影响，因为任一分片丢失都会导致整个原始数据包不可用。

因此，聚合传输协议应控制单包大小，尽量避免 IP 层分片。常见做法是将 UDP payload 控制在较安全范围内，并结合路径 MTU 发现或静态配置选择合适的包大小。
