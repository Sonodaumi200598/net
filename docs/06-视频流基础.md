# 第 6 章 视频流基础

## 6.1 视频编码基础

无人机和无人车实时图像通常使用 H.264 或 H.265 编码。基础技术层需要理解 GOP、I 帧、P 帧、B 帧、码率、帧率、分辨率和关键帧间隔等概念。

I 帧丢失通常会造成较明显画面损伤，P/B 帧丢失影响范围相对较小。因此，后续视频业务感知调度和关键帧保护需要建立在对编码结构的基本理解之上。

## 6.2 视频封装与传输格式

常见视频输入和输出格式包括 RTP/UDP、MPEG-TS/UDP、RTSP、RTMP、H.264 Annex-B 裸流和 H.265 裸流。

在实验模型中，可由 FFmpeg 或 GStreamer 将无人机/无人车视频流转换为聚合路由器可接收的 UDP/RTP 或 MPEG-TS 数据流。

## 6.3 实时视频对网络的要求

- 低时延：保证指挥、巡检或远程驾驶的实时感。
- 低抖动：降低播放端缓存压力，减少卡顿。
- 连续性：避免频繁中断和长时间画面冻结。
- 可容忍轻微丢包：实时视频通常更关注及时到达，而非所有数据完整到达。
- 关键帧保护：降低关键帧丢失导致的连续画面损伤。
- 码率匹配：视频编码码率需要与聚合链路可用带宽匹配。

## 6.4 无人机/无人车视频特点

- 运动画面较多，画面变化快。
- 码率波动明显，复杂场景中编码压力增大。
- 关键帧丢失对画面恢复影响较大。
- 多路摄像头并发回传会显著增加上行带宽压力。
- 实时图像质量直接影响远程观察、决策和控制。
