# 第 1 章 基础技术层概述

## 1.1 基础技术层定位

基础技术层是异构聚合网络视频回传系统的底层支撑层，主要负责提供多链路接入、IP 网络通信、传输协议、路由控制、视频流基础输入输出、网络质量测量和基础安全能力。

该层不直接决定复杂的调度策略和视频质量优化策略，但为上层的多路径调度、链路聚合、乱序重排、丢包恢复、拥塞控制和视频业务适配提供必要的数据通道与基础状态信息。

## 1.2 基础技术层与其他层的关系

整体实验模型可按照如下层次划分：

1. 第一层：基础技术层
2. 第二层：传输控制层
3. 第三层：聚合调度层
4. 第四层：视频业务适配层
5. 第五层：实验评估层

基础技术层向上传递链路可用性、网络接口状态、基础链路质量、数据收发接口、路由控制能力和视频流输入输出能力。

## 1.3 基础技术层研究范围

- 聚合路由器如何接入多种异构网络。
- 聚合路由器如何控制不同数据包从指定链路发出。
- 聚合服务器如何接收来自多条链路的数据。
- 基础网络参数如何影响实时视频回传。
- 实验环境如何模拟带宽、时延、抖动、丢包和链路中断。

## 1.4 基础技术层核心技术清单

- 异构链路接入技术：4G、5G、Wi-Fi、以太网、专网、卫星、Mesh。
- IP 网络技术：IPv4、IPv6、子网、网关、NAT、MTU、路由表。
- Linux 网络技术：多网卡管理、策略路由、Socket、qdisc、抓包诊断。
- 传输协议技术：UDP、TCP、RTP/RTCP、QUIC、SRT、MPTCP、MPUDP、SCTP。
- 视频流基础技术：H.264/H.265、GOP、I/P/B 帧、RTP、MPEG-TS、RTSP。
- 网络质量测量技术：RTT、单向时延、抖动、丢包率、可用带宽、链路在线状态。
- 基础安全技术：身份认证、加密、完整性校验、防重放。
- 实验仿真技术：Linux network namespace、veth、tc netem、Docker、Mininet、ns-3。
