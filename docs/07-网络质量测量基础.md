# 第 7 章 网络质量测量基础

## 7.1 时延测量

时延包括单向时延、往返时延和排队时延。基础实验中通常优先测量 RTT，因为 RTT 更容易通过 ping、UDP probe 或 ACK 反馈获得。

对于实时视频，除了平均时延，还应关注最大时延和 95 分位时延，因为偶发高时延会直接造成画面卡顿或数据包过期。

## 7.2 抖动测量

抖动表示数据包到达间隔的变化程度。抖动过大会导致服务器重排缓存和播放端 jitter buffer 压力增大。

可参考 RTP jitter 的计算思想，也可在实验中基于相邻包到达间隔差值进行统计。

## 7.3 丢包测量

丢包率可通过发送包数、接收包数和序号缺口计算。需要区分随机丢包、连续丢包和突发丢包，因为它们对视频质量和恢复策略的影响不同。

在聚合传输系统中，服务器侧应根据全局序号识别缺失数据包，并向上层提供丢包统计结果。

## 7.4 带宽测量

带宽包括链路标称带宽、可用带宽和实际吞吐量。基础实验可使用 iperf3 测量单链路吞吐，也可通过实际视频包 ACK 间隔、接收速率和发送速率估计可用带宽。

带宽测量结果可作为上层调度权重计算的重要输入。

## 7.5 链路在线状态检测

链路在线状态检测通常通过 heartbeat、keepalive、超时机制和连续探测失败次数实现。链路状态可抽象为 INIT、ACTIVE、DEGRADED、FAILED、RECOVERING 等状态。

基础技术层需要向上层及时报告链路失效和恢复事件。
