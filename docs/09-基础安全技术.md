# 第 9 章 基础安全技术

## 9.1 身份认证

聚合服务器需要确认接入的聚合路由器是否合法。可采用设备 ID、token、证书认证、双向 TLS 和服务器白名单等方式。

## 9.2 数据加密

实时图像回传可能涉及敏感现场画面，需要考虑传输加密。可选技术包括 TLS、DTLS、QUIC 内置加密、WireGuard 和 IPSec。

## 9.3 完整性校验

完整性校验用于发现传输过程中发生的数据损坏或篡改。可采用 checksum、CRC32 或 HMAC。对于自定义 UDP 协议，可在包头中设置校验字段。

## 9.4 防重放机制

防重放机制可基于 timestamp、nonce、sequence number 和接收窗口实现。服务器侧应拒绝明显过期、重复或序号异常的数据包。
